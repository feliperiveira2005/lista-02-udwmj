# Lista 02 - UDWMJ

Lista de Exercícios Práticos de **HTML e CSS** da disciplina Usabilidade, Desenvolvimento Web, Mobile e Jogos.

## Exercícios

1. Cartão de Visitas Digital
2. Perfil de Personagem
3. Receita Simples
4. Botão Estilizado
5. Bloco de Destaque / Card de Notícia
6. Tabela de Preços Simples
7. Rodapé de Site

Cada exercício está organizado em sua própria pasta, com o HTML e o CSS separados.
